# MAGNESS project guidance

- MAGNESS is an independent software consultancy, not an AI-first agency. Keep claims grounded in the founder's approximately ten years of experience.
- Do not invent clients, a team, testimonials, certifications or measured outcomes. Clearly attribute specific previous-role experience.
- Astro, TypeScript and Tailwind are selected. Use React islands only where useful. Keep styling on the shared semantic tokens.
- Preserve the supplied Harbor design direction and the three service descriptions unless the user requests a change.
- Keep credentials server-only and untracked. Tests must use fake email transports, never live email.
- Run `npm run check`, `npm test` and `npm run build` before committing meaningful changes. Check responsive layouts and contact states when UI behavior changes.
- The user authorizes commits and pushes at working milestones. Public deployment is a separate step.
